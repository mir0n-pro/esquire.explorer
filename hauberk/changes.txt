auth.KcTokenClient 
  - plain-Java client_credentials grant against KC /token
auth.RefreshableToken
  - thread-safe access-token holder; lazy first fetch; auto-refresh at TTL-30s
config.HauberkConfig
   - typed config (endpoints, KC client+secret, playground id, prepare/move/super knobs, metrics)
     loaded from hauberk.properties + optional overlay via --config
   - added tokenRelay.type (plain | vanilla | phantom) + isBasicAuth() + basicAuthHeader() 
     so the harness can present HTTP Basic at the edge for Vanilla Token Relay runs; overlay javadoc decoupled from JWS+ naming
config.EntityKinds
    - kind-code constants (ORG=20, USR_CLIENT=34, ACCT_CLIENT=50, TX_DEPOSIT/WITHDRAW/TRANSFER, ...)
health.HealthPreCheck
   - KC well-known + gateway health probes run before sim start; aborts on failure
   - auth-path probe branches on HauberkConfig.AUTH_MODE 
     presents Basic for Vanilla Token Relay, Bearer otherwise; 
perf.PerformanceMatrix
   - per-response transformResponse hook capturing the four observability headers
    (X-Response-Time / Esq-Gw-Inner-Time / Esq-Srv-Outer-Time / Esq-Srv-Inner-Time);
cli.HauberkCli
   - picocli @Command root entry point; dispatches to subcommands

   - programmatic Gatling launch with --metrics, --output, --config, --times, shape knobs
cli.ListCommand
   - catalogue of discovered Simulations with @SimulationInfo descriptions

   - per-URL percentile summary from a saved perf-matrix CSV
cli.DiffCommand
   - side-by-side per-URL diff of two perf-matrix CSV snapshots

   - in-memory snapshot of a perf-matrix CSV (YAML preamble + row arrays)
